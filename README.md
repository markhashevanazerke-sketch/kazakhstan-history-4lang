# История Казахстана — интерактивный сайт

Одностраничный интерактивный курс по истории Казахстана (15 лекций, хронология, вопросы, интерактивная карта, вкладка университета).

**Языки:** Қазақша · Русский · English · 한국어 (переключатель в шапке; выбор запоминается; сразу нужный язык — параметр URL: ?lang=kk / ?lang=ru / ?lang=en / ?lang=ko).

## Запуск
Просто открыть index.html в браузере (файл самодостаточный: все данные и картинки встроены).

## Хостинг
- GitHub Pages: Settings → Pages → Deploy from branch (ветка main, корень) → адрес вида https://USERNAME.github.io/kazakhstan-history-4lang/
- Или любой статический хостинг — файл всего один.

Карты подгружаются из OpenStreetMap (нужен интернет; офлайн-заглушка на карте есть).
